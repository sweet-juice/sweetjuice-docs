Sweet Juice is an open-source Go framework for building native mobile apps with Material You design, deep system integrations, and a plugin-based architecture powered by `gomobile`.

- **Native UI** — Declarative widgets in Go, rendered as native Android views via the `mu3` plugin.
- **Material You** — All built-in components use Material 3 dynamic color theming.
- **Plugin system** — First-party plugins for permissions, notifications, biometrics, files, and more.
- **Cross-platform** — Android and iOS from a single Go codebase.
