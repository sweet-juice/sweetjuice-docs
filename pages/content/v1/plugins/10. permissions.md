The **Permissions** plugin provides a thin, reliable bridge between Go and the Android runtime permission system.

## Setup

The permissions plugin is already registered in the default `AppTemplate`.

## API

### `permission.Check(permission string) (string, error)`

Returns the current status of a single permission.

### `permission.Request(permission string) (string, error)`

Shows the system permission dialog.

### `permission.RequestMultiple(permissions []string) (string, error)`

Requests multiple permissions sequentially.

## Events

### `permissions:changed`

Emitted each time a permission request completes.

```json
{
  "permission": "android.permission.READ_CALL_LOG",
  "granted": true
}
```

## Example

```go
import "github.com/sweet-juice/sweetjuice/plugins/permission"

status, _ := permission.RequestMultiple([]string{
    "android.permission.READ_CALL_LOG",
    "android.permission.READ_SMS",
})
```
